Use Claude Code for free

4 ways. Which to use, and setup in 5 steps
OpenRouterSafe · long-term

Free models only (DeepSeek, Qwen…). Real Claude here is paid.

AgentRouterTest projects only

Real Claude on free signup credits, until they run out.

Free LLM APIFree · runs on your Mac

Joins 34 free providers into one, about 7.4B free tokens a month. Not real Claude.

OllamaFree forever · most private

Runs a model on your own Mac, offline. Slower, and needs 16 GB RAM or more.

  1. Make an API key at openrouter.ai.
  2. Install Claude Code: 
    curl -fsSL https://claude.ai/install.sh | bash
  3. Paste into ~/.zshrc, then run source ~/.zshrc: 
    export OPENROUTER_API_KEY="your-key-here"
export ANTHROPIC_BASE_URL="https://openrouter.ai/api"
export ANTHROPIC_AUTH_TOKEN="$OPENROUTER_API_KEY"
export ANTHROPIC_API_KEY=""
  4. Run claude. If it uses your old login, type /logout and start again.
  5. Type /model and pick one ending in :free.
  1. Sign up at agentrouter.org with GitHub (needs an older, active account).
  2. Make a key in Token Console.
  3. Install Claude Code: 
    curl -fsSL https://claude.ai/install.sh | bash
  4. Paste into ~/.claude/settings.json: 
    {
  "env": {
    "ANTHROPIC_BASE_URL": "https://agentrouter.org",
    "ANTHROPIC_AUTH_TOKEN": "your-agentrouter-key",
    "ANTHROPIC_API_KEY": ""
  }
}
  5. Run claude. Check credits in the AgentRouter dashboard.

  2. Open the dashboard at localhost:3001.
  3. On the Keys page, add free API keys from providers like Google AI Studio, Groq or OpenRouter. You sign up for each one yourself.

Free installs get new models about 30 days late. Paid "Premium" ($19/yr) gets them the same day. It's optional.

  1. Download and install Ollama from ollama.com. Check it is version 0.14 or newer: 
    ollama --version
  2. Install Claude Code if you don't have it: 
    curl -fsSL https://claude.ai/install.sh | bash
  3. Download a coding model. glm-4.7-flash is light (about 6.5 GB) and handles tools well: 
    ollama pull glm-4.7-flash
  4. Start Claude Code on that model with one command: 
    ollama launch claude --model glm-4.7-flash
  5. Work as usual. Nothing leaves your Mac. With 32 GB RAM or more you can try a stronger model like qwen3-coder.

64 GB+Larger models, higher quality24 GB+Best Fastest local setup.

Check yours: Apple menu → About This Mac → Memory. Keep at least 3–4 GB free for macOS itself. Expect local models to answer several times slower than Claude.

Models ending in :cloud are also free but run on outside servers, so they lose the privacy benefit. Local models are much slower than Claude and weaker on big, multi-file tasks.

⚠ With OpenRouter, AgentRouter and cloud models, your code passes through their servers. Keep client code, passwords and .env files away from free relays, and never share your key.

These are not built-in commands. They're short hints at the start of a prompt, and the AI reads the word to guess what you want. They work in ChatGPT and Claude, and writing it in plain words works just as well. Example: /eli5: how do transformers work?
